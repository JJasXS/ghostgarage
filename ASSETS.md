# Asset Attribution

## 3D vehicle models

GhostGarage uses **original procedural concept vehicles** authored in Three.js / React Three Fiber primitives (`src/three/vehicles/ProceduralCar.tsx`).

These models are:

- Fictional concept cars (Ghost GT, Ghost R, Ghost X)
- **Not** production vehicle geometry
- **Not** affiliated with any automotive manufacturer
- Licensed under the same MIT license as the project source code

No third-party GLB/GLTF commercial car assets are bundled.

## Environment lighting

The showroom uses `@react-three/drei` `Environment` with the built-in `city` preset (HDR environment map shipped by the drei package under its own license terms).

## Icons

UI icons are from [Lucide](https://lucide.dev/) (ISC License).

## Textures

No external copyrighted textures are included. Materials are procedural PBR parameters.
